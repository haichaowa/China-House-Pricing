# 中国房价可视化：数据源调研清单

调研日期：2026-09-27  
目的：为“中国地图点击省份/城市放大，展示当月房价、走势、成交、库存及影响因素”的演示动画寻找可用、可信、可交叉验证的数据源。

## 0. 结论先行

1. **没有单一官方网站同时提供全国、分省、分市、当月、可售房源价格、平方米数、库存、成交和历史走势。** 中国官方公开数据通常拆在多个系统中。
2. **最适合作为基准的官方数据源是国家统计局 70 城商品住宅销售价格指数**：月度更新，含新房、二手房，环比/同比，城市级；但只覆盖 70 个大中城市，且是指数，不是挂牌价。
3. **要做 31 个省级行政区的地图色块**，建议用国家统计局/统计年鉴中的分省“商品房销售额 ÷ 商品房销售面积”得到平均交易单价。它不是纯房价涨幅，受成交结构影响，但覆盖完整、权威且口径统一。
4. **要看“当前可售面积/套数/网签成交”**，主要靠城市住建/房管局、房地产交易中心、阳光家缘、网上房地产等地方官方平台。各城市字段和口径差异很大，需要逐市接入。
5. **挂牌价、户型面积、小区/房源级数据**主要来自贝壳/链家、安居客、房天下等平台。适合做“当前市场感知”和分布分析，但存在重复房源、下架延迟、挂牌价不等于成交价等偏差，不能直接当作官方成交价。
6. **国际比较**优先用 BIS、OECD、IMF、Eurostat、各国统计局/中央银行/住建部门。它们多为指数化、季节调整或重复交易指数，与中国平均交易价口径不同，应使用同比/指数化比较，避免直接比较绝对单价。

## 1. 中国房价与成交：优先级最高的数据源

### 1.1 国家统计局：70 城商品住宅销售价格指数

- 网站：<https://www.stats.gov.cn/sj/zxfb/>
- 示例：2026 年 8 月 70 城数据：<https://www.stats.gov.cn/sj/zxfb/202609/t20260915_1965304.html>
- 数据内容：
  - 新建商品住宅销售价格指数
  - 二手住宅销售价格指数
  - 环比、同比
  - 按户型面积段分组：90㎡及以下、90-144㎡、144㎡以上
- 更新频率：月度
- 覆盖：70 个大中城市，通常为直辖市、省会、自治区首府和重点城市
- 优势：
  - 国家级权威
  - 月度更新
  - 新房、二手房均有
  - 城市级，适合做城市趋势图
- 注意：
  - 调查范围为城市市辖区，不包括县
  - 新建商品住宅基础数据采用当地房地产管理部门网签数据
  - 二手住宅为基础调查与典型调查结合，来自经纪机构或居住服务平台上报及实地采价
  - 指数不等于平均挂牌价或平均成交单价
- 建议用途：
  - 城市房价趋势主图
  - 月度同比/环比动效
  - 与商业指数交叉验证

### 1.2 国家统计局：全国房地产市场基本情况

- 发布栏目：<https://www.stats.gov.cn/sj/zxfb/>
- 示例：2026 年 1-8 月全国房地产市场基本情况：<https://www.stats.gov.cn/sj/zxfb/202609/t20260915_1965310.html>
- 数据内容：
  - 房地产开发投资额
  - 住宅、办公楼、商业营业用房投资
  - 房屋施工面积、新开工面积、竣工面积
  - 新建商品房销售面积、销售额
  - 新建商品房待售面积
  - 房地产开发企业到位资金、国内贷款、自筹资金、定金及预收款、个人按揭贷款
  - 住建部提供的二手房交易网签面积
- 更新频率：月度累计
- 覆盖：全国；分省数据可通过国家统计局数据库/统计年鉴获取
- 优势：
  - 官方、稳定、口径全国统一
  - 能反映供给、销售、库存、资金面
- 建议用途：
  - 全国概览
  - 供给端与资金端因素
  - 分省平均交易单价：`商品房销售额 / 商品房销售面积`

### 1.3 国家数据 / 国家统计局数据库与统计年鉴

- 国家数据：<https://data.stats.gov.cn/>
- 中国统计年鉴：<https://www.stats.gov.cn/sj/ndsj/>
- 年鉴示例：<https://www.stats.gov.cn/sj/ndsj/2025/indexch.htm>
- 数据内容：
  - 分省年度/季度/月度宏观经济指标
  - 房地产开发投资、销售额、销售面积
  - GDP、常住人口、城镇化率、居民收入、消费、就业、CPI 等
  - 省级、城市部分指标
- 优势：
  - 官方权威
  - 覆盖全国 31 个省级 region，适合地图
- 注意：
  - 部分数据仅年度
  - 网页/接口可能有防爬、Cookie、编码和历史口径调整问题
  - “平均价”受成交结构影响
- 建议用途：
  - 31 省地图色块的省级基准价格
  - 影响因素面板数据

## 3. 土地市场：地价、溢价率、楼面价、供地节奏

### 3.1 中国土地市场网 / 自然资源部土地市场动态监测

- 网站：<https://landchina.com/>
- 主管系统：自然资源部土地市场动态监测监管相关系统
- 数据内容：
  - 土地供应计划
  - 出让公告
  - 成交公示
  - 供地方式、用途、面积、成交价、受让单位
- 可计算：
  - 楼面价：成交价 / 规划建筑面积
  - 溢价率：成交价 / 起始价
  - 住宅用地成交规模
  - 分城市、分区域土地热度
- 可信度：A：官方
- 注意：
  - 页面可能动态加载、验证码或查询限制
  - 土地价格不能直接等同房价，需要考虑容积率、配建、限价、自持等条件

### 3.2 各省/市自然资源和规划局

- 内容：土地供应计划、出让公告、成交结果、规划条件
- 优势：更适合解释城市新区、板块和地铁沿线供给
- 建议：重点城市逐市采集，与 LandChina 交叉验证

### 商业平台使用建议

1. 官方成交指数用于趋势结论。
2. 商业平台用于挂牌价分布、面积段、户型、小区和热度。
3. 展示时明确写“挂牌价/商业指数/官方网签”。
4. 不要将挂牌价与统计局指数直接画成同一口径曲线。
5. 遵守平台 robots、服务条款和版权，不宜未经授权大规模抓取。

## 10. 数据可信度分级

| 等级 | 定义 | 示例 |
|---|---|---|
| A | 官方一手统计、交易、登记、土地、金融数据 | 国家统计局、地方住建局、LandChina、PBoC、ONS、FHFA、BIS |
| B | 官方关联平台、国际组织、权威研究机构 | 上海网上房地产、OECD、IMF、中指研究院、贝壳研究院 |
| C | 商业平台或方法论透明的市场指数 | 贝壳挂牌、安居客、CRIC、FRED 汇总数据 |
| D | 众包、透明度有限、需强校验 | Numbeo、部分房价行情网站 |

## 11. 主要口径风险

1. **挂牌价 ≠ 成交价**：挂牌价受房东预期、中介策略、重复房源影响。
2. **平均价 ≠ 同质价格**：平均价受位置、户型、郊区成交占比影响；趋势分析应用指数。
3. **网签数据滞后**：新房从认购到网签可能存在时间差。
4. **可售面积口径不统一**：批准预售、现房可售、抵押、限制销售、车位/储藏室等处理方式不同。
5. **70 城指数不覆盖所有县市**：省份地图不能全部用 70 城指数填充。
6. **土地成交价 ≠ 未来房价**：需扣除配建、自持、限房价、容积率差异。
7. **国际房价指数方法不同**：重复交易、平均价、中位数、评估价、按揭样本指数都不能直接混比。
8. **历史数据存在修订**：需要保存版本号和抓取时间。
9. **地图合规**：中国正式发布需使用合规底图和审图号。

## 12. 落地优先级

### 第一阶段：1-2 天原型

1. DataV GeoAtlas 中国省级 GeoJSON。
2. NBS 70 城价格指数最新月和过去 12 个月。
3. 国家统计局/统计年鉴省级平均交易价。
4. ECharts/D3 地图点击放大 + 折线图。

### 第二阶段：数据可信展示

1. 加入地方住建/房管局网签、可售面积。
2. 加入 LandChina 土地成交、楼面价、溢价率。
3. 加入人口、收入、GDP、LPR、贷款余额。
4. 每个指标展示来源、更新时间、口径注释。

### 第三阶段：多方对比

1. BIS/OECD 国际房价指数。
2. 房价收入比、租金收益率、库存与利率。
3. 中国城市与国际城市对比，但统一使用指数化或收入倍数指标。
